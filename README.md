
# Visual Algorithms

A brief description of what this project does and who it's for


## Run Locally

Clone the project

```bash
git clone https://github.com/DarnellBT/algorithms.git
```

Go to the project directory

```bash
cd algorithms
```

Install dependencies

```bash
npm i
```
or
```bash
npm install
```

Start the server

```bash
npm run dev
```
or
```bash
yarn dev
```
